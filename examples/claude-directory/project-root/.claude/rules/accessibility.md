# Accessibility Rules

- Prefer semantic HTML before adding ARIA attributes.
- Ensure all interactive elements have visible labels or accessible names.
- Preserve keyboard navigation and focus visibility.
- Use color and motion in a way that does not hide meaning or state.
- Flag missing alt text, form labels, and dialog semantics during review.
